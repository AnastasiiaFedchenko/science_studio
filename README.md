
# Модификация пайплайна распознавания эмоций на базе MediaPipe: замена классификатора и анализ временных признаков
---
## Аннотация

Статья посвящена исследованию методов классификации эмоций по изображению лица, что представляет собой актуальную задачу для систем человеко-машинного взаимодействия и анализа когнитивных способностей. В рамках разработки тестовых стендов с компьютерным зрением требуется надежный и вычислительно эффективный способ отслеживания мимических реакций, способный функционировать в режиме реального времени на устройствах с ограниченными вычислительными ресурсами. Целью данной работы является проверка гипотезы о том, что замена базового классификатора и добавление временных признаков повышают качество распознавания эмоций без существенного роста вычислительной сложности. В работе предлагается использовать 52-мерные blendshape-коэффициенты (оценки активации мимических мышц), извлекаемые с помощью библиотеки MediaPipe, в качестве компактного и устойчивого к освещению пространства признаков. Рассматривается модификация существующего пайплайна: вместо базового алгоритма Random Forest предлагается применять метод опорных векторов (SVM) и логистическую регрессию. Дополнительно исследуется гипотеза о добавлении межкадровых разностей (temporal differences) для учета динамики мимических изменений. Вычислительный эксперимент проводится на открытом датасете FER-2013 с использованием метрик Accuracy и Macro-F1. Ожидается, что предложенные модификации обеспечат прирост качества классификации для редких и сложных классов эмоций, таких как страх и печаль, по сравнению с базовым уровнем. Полученные результаты позволят определить границы применимости легковесных признаков MediaPipe. Работа предоставляет воспроизводимый пайплайн и закладывает основу для создания эффективных систем детекции реакций.

## Введение и постановка задачи

### Введение

**Проблема.** Анализ когнитивных способностей человека и его эмоционального состояния является важной задачей для современных систем человеко-машинного взаимодействия. В рамках глобального проекта по созданию тестовых стендов с компьютерным зрением (CV) требуется надежный и вычислительно эффективный способ отслеживания мимических реакций. Точное распознавание эмоций позволяет фиксировать скорость реакции и когнитивную нагрузку, однако требует алгоритмов, способных работать в реальном времени.

**Краткий обзор.** Существующие подходы к распознаванию эмоций делятся на две группы. Первая — тяжелые сверточные нейронные сети (CNN), которые показывают высокое качество, но требуют значительных вычислительных ресурсов. Вторая — методы, основанные на извлечении ключевых точек (landmarks) лица и их признаков. В 2023 году в библиотеке MediaPipe появилась возможность извлекать 52 коэффициента blendshapes (оценки активации мимических мышц), которые устойчивы к освещению и повороту головы.

**Ограничения существующих методов.** Использование CNN в мобильных или встроенных системах часто избыточно. Хотя признаки blendshapes хорошо зарекомендовали себя в смежных задачах (например, в анимации лица), их применение для классификации эмоций традиционными алгоритмами машинного обучения исследовано недостаточно. Остается открытым вопрос, можно ли повысить качество классификации за счет простой смены классификатора или добавления временных признаков.

**Предложение.** В данной работе предлагается использовать 52-мерные векторы blendshapes от MediaPipe в качестве пространства признаков. В качестве базовой модели (baseline) используется классификатор Random Forest (точность 51.36% на FER-2013). В качестве модификации предлагается заменить классификатор на SVM или Logistic Regression, а также (в качестве дополнительной гипотезы) добавить межкадровые разности (temporal differences) для учета динамики мимики.

**Вклад.** Работа предоставляет воспроизводимый пайплайн, который показывает, как простые инженерные модификации (смена классификатора) влияют на метрики качества (Macro-F1) при работе с легковесными признаками MediaPipe. Это позволяет заложить основу для более сложных систем детекции реакций в рамках глобального проекта.

### Сравнительная таблица методов

| Альтернативные методы | Сильные стороны | Слабые стороны |
| :--- | :--- | :--- |
| **CNN (например, ResNet, ViT)** | Высокая точность (SOTA), способность улавливать сложные паттерны. | Тяжелые, требуют GPU, сложны в интерпретации, эффект «черного ящика». |

## Формальная постановка задачи

**Общее описание.** Мы решаем задачу классификации эмоций по изображению лица. Дано изображение лица, требуется определить одну из 7 базовых эмоций (Angry, Disgust, Fear, Happy, Sad, Surprise, Neutral). Качество решения измеряется метрикой Macro-F1.

**Обозначения и формальная запись.**
*   **Данные:** Матрица признаков $X \in \mathbb{R}^{n \times d}$, где $n$ — количество изображений, $d = 52$ (размерность вектора blendshapes). Вектор целевой переменной $y \in \{1, \dots, 7\}$ (метки классов).
*   **Отображение:** Класс моделей $H$ — параметрическое семейство $f(x, w)$, где $w \in W$ — параметры классификатора (Random Forest, SVM или Logistic Regression).
*   **Внутренний критерий:** Функционал качества $Q(w)$, который оптимизируется алгоритмом (например, минимизация энтропии/джини для Random Forest или Hinge loss для SVM).
*   **Внешний критерий:** Macro-F1, точность (Accuracy), полнота (Recall) и матрица ошибок, понятные для конечного пользователя.

**Задача оптимизации:**
$
w^* = \arg \min_{w \in W} Q(w)
$
где $w^*$ — оптимальные параметры классификатора, обеспечивающие наилучшее разделение классов на контрольной выборке.

## Планирование вычислительного эксперимента

### 1. Цель эксперимента
Проверить гипотезу $H_1$: замена базового классификатора (Random Forest) на SVM или Logistic Regression при фиксированных blendshape-признаках улучшит Macro-F1 на датасете FER-2013. Дополнительно проверить гипотезу $H_2$: добавление межкадровых разностей (если данные позволяют) улучшит разделение сложных классов.

### 2. Описание набора данных
*   **Название:** FER-2013.
*   **Источник:** Открытый датасет, представленный на ICML 2013, доступен через HuggingFace / Kaggle.
*   **Условия измерений:** Изображения лиц в градациях серого, разрешение 48×48 пикселей. Схема измерения: статические изображения.
*   **Объем:** 35 887 изображений, 7 классов эмоций. Признаки извлекаются предварительно (52 значения на изображение).

### 3. Конфигурация эксперимента
*   **Параметры алгоритма:**
    *   `MediaPipe Face Landmarker`: извлечение 52 blendshape-коэффициентов.
    *   `Baseline Random Forest`: 200 деревьев, `class_weight='balanced'`.
    *   `SVM`: ядро RBF, подбор параметров $C$ и $\gamma$ через GridSearchCV.
    *   `Logistic Regression`: мультиномиальный, `class_weight='balanced'`.
*   **Процедура валидации:** Разбиение выборки на Train/Test (например, 80/20) с сохранением пропорций классов (stratify), либо 5-fold кросс-валидация.
*   **Воспроизводимость:** Все случайные процессы фиксируются (`random_state=42`).

### 4. Этапы (Базовый эксперимент и сравнение)
1.  **Базовый эксперимент:** Запуск Random Forest на исходных признаках (воспроизведение baseline 51.36%).
2.  **Сравнение с альтернативами:** Запуск SVM и Logistic Regression на тех же признаках. Сравнение метрик.
3.  **Анализ свойств:** Анализ матрицы ошибок. Проверка гипотезы $H_2$ (если данные поддерживают последовательности кадров, например, при тестировании на видео, а не на статичном FER-2013).

### 5. Ожидаемые таблицы и рисунки
*   **Таблица 1:** Сравнение метрик Accuracy и Macro-F1 для Baseline (RF), M1 (SVM) и M2 (LR).
*   **Рисунок 1:** Столбчатая диаграмма (Bar chart) значений Macro-F1 для трех конфигураций.
*   **Рисунок 2:** Матрица ошибок (Confusion Matrix) для лучшей модели, показывающая, какие классы (например, Fear и Sad) чаще всего путаются.

### 6. Ожидаемые результаты (черновик рисунка)
Ожидается, что SVM покажет прирост Macro-F1 на 2–5% по сравнению с Random Forest за счет лучшей работы с нелинейными границами классов, особенно для редких эмоций (Fear, Disgust).
